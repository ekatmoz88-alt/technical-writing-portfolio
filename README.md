# Technical Writing Portfolio

REST API / OpenAPI Documentation Portfolio

**Focus:** REST API · OpenAPI 3.1 · Developer Documentation · Docs-as-Code · EN/RU

## Overview

A demonstration portfolio documenting a fictional Orders API. It showcases how I structure API documentation for developers and integrators, from the OpenAPI contract to onboarding guides and webhook instructions.

## What this portfolio demonstrates

- API reference design and information architecture.
- OpenAPI 3.1 specification authoring.
- REST API endpoint, parameter, schema, and response documentation.
- Request/response examples and error handling.
- Webhook events, payloads, signature verification, and retries.
- Developer onboarding guides.
- Docs-as-Code workflows using Markdown and Git.
- Documentation review and validation checklists.
- English/Russian documentation structure.

## Tooling

OpenAPI 3.1 · YAML · Markdown · Git · Postman/cURL · API documentation workflows

## Approach

- **Spec-first:** OpenAPI is the structured contract for the API reference.
- **Developer-first:** guides and examples focus on helping integrators complete tasks.
- **Docs-as-Code:** documentation sources are versioned in Git and organized for review.
- **Consistency:** reusable structures and terminology support maintainable documentation.
- **Bilingual:** English and Russian portfolio materials.

## Project context

The Orders API is illustrative/simulated. It is a portfolio exercise demonstrating documentation structure and artifacts, not a live production service.
