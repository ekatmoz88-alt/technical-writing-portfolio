# Technical Writing Portfolio: обзор проекта

## Назначение

Портфолио API-документации на примере вымышленного Orders API. Демонстрирует OpenAPI 3.1, справочник REST API, руководство разработчика, обработку ошибок, webhooks и подход Docs-as-Code.

## Ключевые материалы

- `openapi/openapi.yaml` — контракт OpenAPI.
- `docs/api-reference.md` — справочник API.
- `docs/error-handling.md` — обработка ошибок.
- `docs/webhooks.md` — события и webhooks.
- `docs/developer-guide.md` — руководство интегратора.
- `docs/documentation-workflow.md` — процесс работы с документацией.

## Принципы

- OpenAPI — структурированный источник сведений об API.
- Примеры запросов и ответов должны соответствовать спецификации.
- Используйте единые термины и последовательные заголовки.
- Поддерживайте EN/RU материалы синхронно.

## Ограничения

Orders API — демонстрационный пример, а не работающий production-сервис.
